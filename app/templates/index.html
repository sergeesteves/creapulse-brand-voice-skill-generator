      Comment l'utiliser
      
      
      Le profil dit COMMENT écrire, pas QUOI écrire. Une fois en place, donnez simplement votre sujet.
      
      
      Dans ChatGPT
      
      
        
        
      • Pour un espace de travail dédié : créez un Projet (barre latérale → Projets → Nouveau projet), ouvrez ses Instructions et collez le bloc prompt. Toutes les conversations du projet écriront dans votre voix.
        • 
        
      • Pour un assistant partageable : Explorer les GPT → Créer, onglet Configurer, collez le bloc dans Instructions. Vous pouvez aussi joindre le fichier SKILL.md dans Connaissances, en plus.
        • 
        
      • Pour toutes vos conversations : Paramètres → Personnalisation → Instructions personnalisées, collez le bloc dans « Comment ChatGPT doit-il répondre ? ».
        • 
      
      
      
      Dans Claude
      
      
        
        
      • Skill (recommandé) : téléchargez le .zip ci-dessus, puis dans Claude (app ou claude.ai) : Paramètres → Capacités (Capabilities) → Skills → Importer / Upload skill et choisissez le zip. Claude chargera la voix tout seul dès qu'une tâche de rédaction s'y prête.
        • 
        
      • Projet : créez un Projet et collez le bloc prompt dans ses instructions (ou en début de conversation).
        • 
        
      • Claude Code : dézippez dans ~/.claude/skills/ (vous obtenez ~/.claude/skills/voix-<marque>/SKILL.md).
        •

      Questions fréquentes
      
    
      Que fait exactement l'outil ?
      Il lit le texte principal de vos pages, puis un modèle de langage en distille les règles de votre voix sur 5 axes : ton, style de phrase, vocabulaire (mots-signature et mots à éviter), structure, principes éditoriaux. Chaque trait est ancré sur des tournures réellement présentes dans vos textes. Rien n'est inventé.
      
    
      Pourquoi mes URLs sont refusées ?
      Parce que l'extraction est vide ou trop courte : page d'accueil, catégorie, page vitrine, paywall, ou site qui bloque les robots. Une mauvaise extraction donnerait un profil bidon, on préfère refuser proprement. Prenez des articles complets, de {{ min_words }} mots minimum.
      
    
      Le résultat est-il stable ?
      Oui, la distillation tourne à température basse : mêmes URLs, même profil (à quelques mots près).
      
    
      Que stockez-vous ?
      Rien du contenu de vos pages, et rien du profil généré par défaut : seulement des compteurs d'usage anonymes. Si vous cochez « Garder ce profil », ce profil-là est rangé dans « Mes profils », avec l'adresse et le titre des articles lus ; il est effacé au bout de la durée de conservation indiquée, et vous pouvez le supprimer vous-même à tout moment. Sans la case, rien n'est gardé. Votre compte Creapulse sert à vous identifier et à tenir votre solde de crédits. Voir la politique de confidentialité.
      
    
      Combien coûte une génération ?
      Chaque génération consomme des crédits de votre porte-monnaie Creapulse, le même pour tous les outils ; le prix s'affiche à côté du bouton. Rien n'est débité si vos pages sont refusées, et une génération qui échoue est remboursée. À la création du compte, des crédits de bienvenue vous permettent d'essayer.
      
    
      Skill ou bloc prompt ?
      Le bloc prompt marche partout, c'est le défaut. Le skill est le même contenu, emballé pour Claude Code et les runtimes qui chargent des skills automatiquement. Tout est dedans dans les deux cas, aucun fichier externe.
